# حساب‌یار معاملات — سورس آزمایشی اندروید

این بسته سورس پروژه اندروید و گردش‌کار ساخت APK در GitHub Actions را دارد. **خود فایل APK هنوز داخل بسته نیست.**

## امکانات موجود در نمونه اولیه
- رابط فارسی و راست‌چین
- ثبت معامله با نام، تاریخ واردشده توسط کاربر، خرید، فروش و مجموع هزینه‌ها
- ثبت چند شریک و سرمایه اولیه هر نفر
- محاسبه سود/زیان پس از کسر هزینه‌ها و تقسیم متناسب با سرمایه ثبت‌شده
- ذخیره اطلاعات معاملات روی گوشی
- نمایش گزارش و حذف معامله
- تهیه پشتیبان متنی JSON از طریق اشتراک‌گذاری اندروید

## محدودیت‌های فعلی
- تاریخ شمسی باید دستی وارد شود؛ انتخابگر تقویم شمسی وجود ندارد.
- هزینه‌ها فعلاً یک مبلغ کلی هستند؛ ریزهزینه و ثبت پرداخت‌کننده هر هزینه هنوز پیاده‌سازی نشده است.
- خروجی اکسل و بازیابی مستقیم فایل پشتیبان هنوز پیاده‌سازی نشده‌اند.
- این نسخه برای آزمایش اولیه است و پیش از استفاده با اطلاعات مالی واقعی باید کامل‌تر و آزمایش شود.

## ساخت APK فقط با گوشی (از طریق GitHub Actions)
1. در GitHub حساب بسازید یا وارد حساب خود شوید.
2. یک مخزن جدید بسازید (Repository). اگر نمی‌خواهید سورس عمومی باشد، Private را انتخاب کنید.
3. ZIP را از حالت فشرده خارج کنید و محتویات پوشه `hesabyar-android` را در مخزن بارگذاری کنید؛ پوشه `.github` را هم حتماً بارگذاری کنید.
4. به زبانه **Actions** مخزن بروید و در صورت درخواست، فعال‌سازی Actions را تأیید کنید.
5. گردش‌کار **Build HesabYar Android APK** را انتخاب و روی **Run workflow** بزنید.
6. وقتی اجرا سبز و موفق شد، همان صفحه اجرا را باز کنید و از بخش **Artifacts** فایل `HesabYarMoamelat-debug-apk` را دانلود کنید.
7. ZIP دانلودشده را باز کنید تا `app-debug.apk` را ببینید. آن را روی گوشی نصب کنید. ممکن است اندروید اجازه نصب از آن مرورگر یا فایل‌منیجر را بخواهد؛ فقط اگر فایل را از مخزن خصوصی خودتان ساخته‌اید اجازه دهید.

ساخت آنلاین به حساب GitHub و اینترنت نیاز دارد. موفقیت ساخت تا پایان اجرای گردش‌کار تضمین‌شده نیست؛ اگر خطا رخ داد، باید گزارش اجرای Actions بررسی شود.
